## How to use a webpage reference

1. Name the register in one sentence ("warm paper editorial with sage rules").
2. Lock a type pair before layout.
3. Build the content outline before decoration.
4. Add at most one signature interaction.
5. Check 375px width and `prefers-reduced-motion`.
